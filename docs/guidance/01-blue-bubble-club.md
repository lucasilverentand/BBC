# Blue Bubble Club

On 2026-10-29, Luca requested extracting Seven’s iMessage system into <b>Blue Bubble Club</b>, an open-source project in his personal [lucasilverentand/BBC](https://github.com/lucasilverentand/BBC) repository. The intended product is a simple self-hosted alternative in Sendblue’s category: <b>one Swift executable with a small Mac app and an embedded API</b>. Operators create and revoke API keys inside the app and decide how clients reach their Mac. Luca also requested a startup toggle: use macOS Start at login for the signed-in Messages session, with a separate option to start the API when the app opens. Keep execution local to that Mac; do not add distributed services, a separate server stack or managed remote-access infrastructure.

Luca wants permission setup presented as a checklist, with a small floating helper that remains beside System Settings and provides a draggable app icon for permission lists. The icon direction is a centred, white filled iMessage chat bubble with native Icon Composer translucency over clouds, built as distinct layers. Luca’s manually adjusted and saved Icon Composer document is the accepted composition: use its cloud photograph, layer placement and native glass settings without retuning them. Retain the white source symbol and apply its see-through effect through Icon Composer’s material settings. The placement and native material correction are in [BBC PR 11](https://github.com/lucasilverentand/BBC/pull/11). Give the bubble clear separation from the cloud banks, especially along its lower edge and tail, and check that its silhouette remains recognisable at Dock size. The contrast adjustment is in [BBC PR 10](https://github.com/lucasilverentand/BBC/pull/10). Keep it recognisably white while allowing the clouds to show through softly; the material adjustment is in [BBC PR 9](https://github.com/lucasilverentand/BBC/pull/9). The earlier layered composition used transparent cloud artwork underneath and Apple’s standard message.fill symbol in white above it; Luca’s saved Icon Composer version replaces the cloud artwork with a photograph. The white filled foreground is specified in [BBC PR 8](https://github.com/lucasilverentand/BBC/pull/8). The layered source and native symbol generator are in [BBC PR 7](https://github.com/lucasilverentand/BBC/pull/7). BBC should use modern Liquid Glass icons with the standard macOS footprint, shadow and clean continuous edge, preserving the bubble/cloud artwork. The material and edge effects should come from native rendering. Source artwork and packaging are in [BBC PR 5](https://github.com/lucasilverentand/BBC/pull/5); the enabled Liquid Glass material settings are in [BBC PR 6](https://github.com/lucasilverentand/BBC/pull/6).

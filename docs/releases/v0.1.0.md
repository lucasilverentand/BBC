# Blue Bubble Club 0.1.0

BBC is a self-hosted iMessage API in one local Mac app, with app-managed access keys, a Swift SDK and an embedded native bridge.

## Requirements and installation

- Apple Silicon and macOS 26 or later. This app release does not support Intel Macs.
- A Mac configured for Messages. Development and fixture tests can run without an iMessage account.
- Follow the [setup guide](../setup.md) for Full Disk Access, per-key API permissions and optional native features. Native features require separately chosen SIP and library-validation changes; notarization does not perform those changes or establish live private-API compatibility.

Download the release ZIP, verify it against `SHA256SUMS`, and extract the app. Before replacing an existing app, keep it for rollback and preserve the local BBC data and keys. A change from Apple Development to Developer ID signing may require granting Full Disk Access and Messages Automation again.

## Included

- Local authenticated HTTP API and Swift SDK for reading conversations, replies, attachments and thread metadata.
- Native reply targeting and exact database confirmation, with uncertain operations retained for reconciliation and no automatic mutation retries.
- Webhooks, scheduled sends and capability-gated native operations.
- Account-free regression suites using synthetic databases and bridge peers, plus portable SDK and runner coverage.

## Release verification

The distribution workflow publishes artifacts only after Developer ID signing, accepted Apple notarization, stapling and Gatekeeper checks. The attached `manifest.json` records the exact source commit, toolchain, architecture, signer Team ID and submission ID. Source preparation alone does not establish that these checks have run; use the manifest and actual release assets as evidence.

Native capability and delivery limits remain documented in the [native feature guide](../native-features.md). Synthetic tests establish BBC's contracts, not successful live delivery on every macOS version.

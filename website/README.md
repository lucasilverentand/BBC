# Marketing website

A static, dependency-free landing page for Blue Bubble Club. Open `index.html` directly, or serve this directory with any static host. There is no build step, analytics, external font or runtime service. It uses the system font stack and follows the visitor's light or dark appearance. The optional JavaScript only adds Copy buttons to the code samples; all content and navigation work without it.

Keep `index.html`, `styles.css`, `script.js` and `assets/` together when serving the site. Hosting and deployment are not configured. Documentation links point to the public repository so they also work outside GitHub.

`assets/app-icon.png` is a copy of the accepted `Assets/AppIcon.png`. Keep the app's Icon Composer source unchanged; refresh this copy when the accepted exported icon changes. The "Thread anatomy" panel is a labelled illustration that maps API routes to parts of a direct chat. It is not a screenshot of BBC or Messages, and it is not a live connection.

Feature claims, requirements, capability tiers, selected routes and native capability limits follow the repository's README and setup, API, access-control and testing guides. Update the page alongside those contracts when capabilities change. Don't add stars, download counts, user claims or compatibility statements the repository cannot support.
